# 关键点 · 出题规范

本文件是「关键点」题库的**唯一出题依据**。界面上的「生成题库」会把这份文件喂给 AI，
让它按这里的约定批量出题。**想调整 AI 的出题风格，改这个文件即可。**

---

## 一、目标

题目只考察一件事：**孩子能不能读懂题干、抓住关键信息、说清这道题到底在问什么。**
不考计算能力，也不考知识点本身——考的是"读题"。

## 二、面向对象

中国**小学四到六年级**学生。

## 三、学科与题型

每个学科 5 个题型。出题时题型由调用方指定，必须严格符合该题型的定位。

| 学科 | 题型 | 定位 |
|---|---|---|
| 语文 | 概括题 | 概括段意、主要内容、中心思想 |
| 语文 | 词句理解 | 理解词句在语境中的意思、体会含义 |
| 语文 | 赏析题 | 品析修辞、写法、用词的好处 |
| 语文 | 按要求写句子 | 仿写、造句、句式变换 |
| 语文 | 古诗文 | 理解诗句、文言词句的意思 |
| 数学 | 购物问题 | 单价 × 数量，含优惠促销 |
| 数学 | 面积与周长 | 长方形、正方形的面积与周长 |
| 数学 | 单位换算 | 长度、质量、时间等单位的统一 |
| 数学 | 行程问题 | 速度、时间、路程的关系 |
| 数学 | 多步应用题 | 含"剩下""最多"等条件的多步题 |
| 英语 | 疑问词理解 | Where / What / Who / When / How many … |
| 英语 | 句型要求 | 用指定句型写句子 |
| 英语 | 判断正误 | 按短文判断对错、改错 |
| 英语 | 词形填空 | 用单词的正确形式填空 |
| 英语 | 对话交际 | 选择应答、补全对话 |

## 四、难度

- **基础**：信息点少、干扰弱，一眼能看出关键信息。
- **进阶**：信息点多，含隐藏条件或容易看漏的陷阱词（单位不统一、"最多/至少"、"并说明"等）。
- **挑战**：题干更长、逻辑更绕，必须先把"问什么"想清楚才能动手。

## 五、每道题必须包含

1. **stem** —— 题干原文，20~60 字。学科不同形态不同：语文是阅读/写作题的题干；
   数学是应用题题干（含数据、单位、条件、问题）；英语可中英混排。
2. **keywords** —— 3~5 处关键信息，每处含：
   - `text`：题干中的原文片段，**必须与 stem 逐字一致**；
   - `reason`：为什么它是关键信息（讲给孩子听，20 字内）；
   - `role`：`task`（做什么）/ `object`（对象、范围）/ `data`（数据、单位）/
     `condition`（限制条件）/ `target`（最终要问的）/ `trap`（易漏的陷阱词）。
3. **options** —— 4 个"这道题在问什么"的说法，**恰好 1 个正确**，另外 3 个是**近似干扰项**。
   三个干扰项要分别对应常见的读题错误：看错范围 / 答非所问 / 只答一半 / 混淆概念。
   每个含：`text`（说法）、`correct`（对错）、`analysis`（为什么对/错，点破是哪种读题毛病，30 字内）。
4. **tip** —— 一句话解题提示，30 字内。

## 六、输出格式

**严格输出 JSON，不要任何多余文字、不要 markdown 代码块以外的说明**：

```json
{
  "stem": "",
  "keywords": [{ "text": "", "reason": "", "role": "task" }],
  "options": [
    { "text": "", "correct": true, "analysis": "" },
    { "text": "", "correct": false, "analysis": "" },
    { "text": "", "correct": false, "analysis": "" },
    { "text": "", "correct": false, "analysis": "" }
  ],
  "tip": ""
}
```

## 七、自检（出题后请对照）

- 4 个选项里**有且仅有 1 个** `correct: true`；
- 每个 `keywords[].text` 都能在 `stem` 里**原样找到**；
- 干扰项不能一眼假，要"像真的"，对应真实的读题毛病；
- 题干本身要通顺、像真的小学题，不要出现"某题""某某"这类占位词。
