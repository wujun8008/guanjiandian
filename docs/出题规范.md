# 关键点 · 出题规范

本文件是「关键点」题库的**唯一出题依据**。界面上的「生成题库」会把这份文件喂给 AI，
让它按这里的约定批量出题。**想调整 AI 的出题风格，改这个文件即可。**

题目分两种形态：

- **普通题**（大多数题型）：题干 + 4 个"这道题在问什么"的选项；
- **分组题**（数学「选知识点」、英语「判断句型」）：题干 + 若干"组"选项，每组多选或单选。

---

## 一、目标

题目只考察一件事：**孩子能不能读懂题干、抓住关键信息、看清这道题的结构。**
不考计算能力本身——考的是"读题"。

## 二、面向对象

中国**小学四到六年级**学生。

## 三、学科与题型

每个学科 5~6 个题型。出题时题型由调用方指定，必须严格符合该题型的定位。

| 学科 | 题型 | 定位 | 形态 |
|---|---|---|---|
| 语文 | 概括题 | 概括段意、主要内容、中心思想 | 普通题 |
| 语文 | 词句理解 | 理解词句在语境中的意思 | 普通题 |
| 语文 | 赏析题 | 品析修辞、写法、用词的好处 | 普通题 |
| 语文 | 按要求写句子 | 仿写、造句、句式变换 | 普通题 |
| 语文 | 古诗文 | 理解诗句、文言词句的意思 | 普通题 |
| 数学 | 购物问题 | 单价 × 数量，含优惠促销 | 普通题 |
| 数学 | 面积与周长 | 长方形、正方形的面积与周长 | 普通题 |
| 数学 | 单位换算 | 长度、质量、时间等单位的统一 | 普通题 |
| 数学 | 行程问题 | 速度、时间、路程的关系 | 普通题 |
| 数学 | 多步应用题 | 含"剩下""最多"等条件的多步题 | 普通题 |
| 数学 | **选知识点** | 判断一道题用到了哪些知识点 | **分组题** |
| 英语 | 疑问词理解 | Where / What / Who / When / How many… | 普通题 |
| 英语 | 句型要求 | 用指定句型写句子 | 普通题 |
| 英语 | 判断正误 | 按短文判断对错、改错 | 普通题 |
| 英语 | 词形填空 | 用单词的正确形式填空 | 普通题 |
| 英语 | 对话交际 | 选择应答、补全对话 | 普通题 |
| 英语 | **判断句型** | 分析一句话的句型、时态、单复数 | **分组题** |

## 四、难度

- **基础**：信息点少、干扰弱，一眼能看出关键。
- **进阶**：信息点多，含隐藏条件或容易看漏的陷阱。
- **挑战**：更长、更绕，必须先想清楚"问什么/什么结构"才能动手。
  分组题在挑战难度可以**多加几组**（层数更多）。

## 五、普通题的字段

1. **stem** —— 题干原文，20~60 字。
2. **keywords** —— 3~5 处关键信息：`text`（**必须与 stem 逐字一致**）、`reason`（20 字内）、
   `role`（`task`/`object`/`data`/`condition`/`target`/`trap`）。
3. **options** —— 4 个"这道题在问什么"的说法，**恰好 1 个正确**，另外 3 个是**近似干扰项**，
   分别对应看错范围 / 答非所问 / 只答一半 / 混淆概念。每项 `{ text, correct, analysis }`。
4. **tip** —— 一句话提示，30 字内。

## 六、分组题的字段

1. **stem** —— 题干（数学是一道题；英语是一句话）。
2. **groups** —— 若干组，每组：
   - `label`：组名（如"这道题用到的知识点""句型""时态"）；
   - `multiple`：`true` 多选 / `false` 单选；
   - `options`：选项文字（3~4 个，干扰项要像真的）；
   - `correct`：正确选项的**下标数组**（单选时只有 1 个）；
   - `notes`：与 `options` **一一对应**的逐项说明（可留空字符串）。
3. **tip** —— 一句话提示。

**「判断句型」的分层建议**（难度越高，组越多）：

- 基础：句型
- 进阶：句型 + 时态 + 三单
- 挑战：句型 + 时态 + 三单 + 单复数 + 可数不可数

各组的常用选项：

- 句型：主谓宾 / 主系表 / 存在句
- 时态：一般现在时 / 现在进行时 / 一般过去时 / 一般将来时
- 三单：是 / 否
- 单复数：单数 / 复数
- 可数不可数：可数 / 不可数

## 七、输出格式

**严格输出 JSON，不要任何多余文字。** 普通题：

```json
{
  "stem": "",
  "keywords": [{ "text": "", "reason": "", "role": "task" }],
  "options": [
    { "text": "", "correct": true, "analysis": "" },
    { "text": "", "correct": false, "analysis": "" },
    { "text": "", "correct": false, "analysis": "" },
    { "text": "", "correct": false, "analysis": "" }
  ],
  "tip": ""
}
```

分组题：

```json
{
  "stem": "",
  "groups": [
    {
      "label": "句型",
      "multiple": false,
      "options": ["主谓宾", "主系表", "存在句"],
      "correct": [2],
      "notes": ["……", "……", "There be 表示某处有某物"]
    }
  ],
  "tip": ""
}
```

## 八、自检（出题后请对照）

- 普通题：4 个选项里**有且仅有 1 个** `correct: true`；
- 分组题：`correct` 里的下标都真实存在，且单选组只有 1 个；
- 普通题：每个 `keywords[].text` 都能在 `stem` 里**原样找到**；
- 干扰项不能一眼假，要"像真的"；
- 题干本身要通顺、像真的小学题，不要出现"某题""某某"这类占位词。
